# 이학정 남동구의원 민원·소통 사이트 — 설정 가이드

이 폴더의 파일들을 **GitHub Pages(placefarm.github.io)** 에 올리고,
**Google 스프레드시트 + Apps Script** 를 무료 백엔드(DB)로 연결하면
민원 접수·진행조회·후원문의가 모두 동작합니다.

전체 순서는 4단계입니다. 순서대로 따라오시면 됩니다.

- **1단계.** Google 스프레드시트 만들기 (DB)
- **2단계.** Apps Script 백엔드 배포 → 웹앱 주소 받기
- **3단계.** `config.js` 에 웹앱 주소 붙여넣기
- **4단계.** GitHub Pages 에 파일 올리기 (사이트 공개)

## 1단계 · Google 스프레드시트 만들기 (DB)

1. [https://sheets.google.com](https://sheets.google.com) 에서 **빈 스프레드시트** 새로 만들기
2. 이름을 예: `이학정 민원DB` 로 지정
3. 시트(탭)는 그냥 두세요. **Apps Script가 처음 실행될 때 `민원` / `함께하기` 시트를 자동으로 만들고 제목줄도 넣어줍니다.**

> 이 스프레드시트가 곧 **관리자 화면**입니다. 별도 관리자 페이지가 없어도,
> 담당자는 `민원` 시트의 **상태** 칸만 바꾸면 홈페이지 진행조회에 즉시 반영됩니다.

## 2단계 · Apps Script 백엔드 배포

1. 방금 만든 스프레드시트에서 상단 메뉴 **확장 프로그램 → Apps Script** 클릭
2. 왼쪽 위 **"제목 없는 프로젝트"** 를 클릭해 프로젝트 이름을 예: `이학정 민원 백엔드` 로 바꾸기
   *(선택 사항이지만 나중에 프로젝트를 구분하기 쉽습니다. 4단계 배포창의 '설명'과는 별개입니다.)*
3. 기본으로 열린 `Code.gs` 내용을 모두 지우고, 이 폴더의 **`Code.gs` 전체 내용을 복사해 붙여넣기**
4. 💾 저장(디스크 아이콘)
5. 우측 상단 **배포 → 새 배포** 클릭
   - 유형 선택(톱니바퀴) → **웹 앱**
   - 설명: `민원 백엔드` (아무거나)
   - **실행 계정: 나(본인 Gmail)**
   - **액세스 권한: 모든 사용자(Anyone)** ← 반드시 이걸로 해야 홈페이지에서 접근됩니다
   - **배포** 클릭
6. 처음이면 **권한 승인** 창이 뜹니다 → 본인 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → 허용
   *(내가 만든 스크립트라 정상입니다. 스프레드시트 접근·메일 발송 권한을 승인하는 절차)*
7. 배포가 끝나면 나오는 **웹 앱 URL** 을 복사하세요.
   `https://script.google.com/macros/s/xxxxxxxx/exec` 형태입니다.

### (선택) 상태 변경 시각 자동 기록
담당자가 상태를 바꾸면 "최근 업데이트" 시각이 자동으로 찍히게 하려면:
1. Apps Script 왼쪽 **트리거(시계 아이콘)** → **트리거 추가**
2. 실행할 함수: `onEditUpdate` / 이벤트 소스: **스프레드시트에서** / 이벤트 유형: **수정 시**
3. 저장

## 3단계 · config.js 에 주소 붙여넣기

`config.js` 파일을 열어 `API_URL` 값을 2단계에서 복사한 **웹 앱 URL**로 바꿉니다.

```js
window.SITE_CONFIG = {
  API_URL: "https://script.google.com/macros/s/xxxxxxxx/exec",  // ← 여기에 붙여넣기
  OFFICE_EMAIL: "yes2plasma@gmail.com"
};
```

저장합니다. (이 값이 비어 있으면 폼에 "서버 주소가 설정되지 않았습니다" 안내가 뜹니다.)

## 4단계 · GitHub Pages 에 올리기

`placefarm.github.io` 는 **사용자 페이지**이므로 저장소 이름이
`placefarm.github.io` 인 리포지토리의 **루트**에 파일을 올리면 됩니다.

### 방법 A — 웹에서 업로드(가장 쉬움)
1. [github.com/placefarm/placefarm.github.io](https://github.com/placefarm/placefarm.github.io) 접속
2. **Add file → Upload files**
3. 이 폴더의 **모든 파일**(`.html`, `style.css`, `config.js`)을 끌어다 놓기
   - ⚠️ `Code.gs` 와 `README-설정가이드.md` 는 **올리지 않아도 됩니다**(백엔드/문서용).
4. **Commit changes**
5. 1~2분 뒤 **https://placefarm.github.io/** 에서 확인

### 방법 B — git 명령
```bash
git clone https://github.com/placefarm/placefarm.github.io.git
cd placefarm.github.io
# 이 폴더의 html/css/js 파일들을 복사해 넣기
git add .
git commit -m "이학정 남동구의원 민원 사이트"
git push
```

> 기존 테스트 사이트를 덮어쓰는 것이 걱정되면, 먼저 기존 `index.html` 등을
> 백업해 두세요. GitHub에는 커밋 이력이 남아 되돌릴 수 있습니다.

## 개인정보·법적 유의사항 (중요)

- **개인정보 노출 방지:** 진행조회는 접수번호+비밀번호로만 되며, 화면에 이름·연락처를
  절대 표시하지 않습니다. 개인정보 원본은 **본인만 접근 가능한 스프레드시트**에만 저장됩니다.
- **스프레드시트 공유 금지:** DB 시트를 절대 "링크가 있는 모든 사용자"로 공개하지 마세요.
  본인(관리자) 계정에서만 열리도록 두어야 합니다.
- **개인정보처리방침:** `privacy.html` 이 홈페이지에 게시됩니다. 보유기간·책임자 등
  실제 운영에 맞게 확인/수정하세요.
- **후원회(정치자금법):** `support.html` 의 계좌는 **관할 선거관리위원회에 등록된
  후원회 예금계좌**여야 합니다. 온라인 후원·정치자금영수증 발급은 **회계책임자**가
  중앙선관위 규정에 따라 처리해야 합니다. 등록 여부와 절차는 반드시 선관위에 확인하세요.
  *(본 안내는 법률 자문이 아닙니다.)*
- **입당 절차:** 실제 당원 가입은 **더불어민주당 공식 시스템**을 통해 진행되며,
  `join.html` 은 안내·연락용 접수입니다.

## 자주 묻는 문제

**Q. 폼을 눌러도 "서버 주소가 설정되지 않았습니다"가 떠요.**
→ `config.js` 의 `API_URL` 이 비었거나 `http`로 시작하지 않습니다. 3단계 확인.

**Q. "네트워크 오류"가 떠요.**
→ Apps Script 배포 시 **액세스 권한이 '모든 사용자'** 인지 확인하세요.
  코드 수정 후에는 **배포 → 배포 관리 → 편집(연필) → 버전 '새 버전'** 으로 재배포해야 반영됩니다.

**Q. 메일이 안 와요.**
→ Gmail 발송 한도(하루) 문제이거나 스팸함일 수 있습니다. 접수 자체는 시트에 정상 저장됩니다.

**Q. 접수번호 규칙은?**
→ `MW-날짜-일련번호` (예: `MW-20260823-0001`). 같은 날은 0001부터 증가합니다.
